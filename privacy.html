Note Ferry privacy policy

Last updated: 26 November 2026.

Note Ferry is a personal macOS app that runs on the user's own computer. Its developer operates no server for it and receives no data from it. It contains no analytics, advertising or tracking.

Apple Notes

The app reads Apple Notes in order to export the notes the user selects. It does not send them to the developer.

Google user data

If the user connects Google Drive, the app asks for the drive.file permission only. With it, the app can see and manage only the files and folders it created or that the user opened with it, not the rest of the user's Drive.

  • Use: to create the export folders, upload the exported documents, update them on later exports, and check whether they already exist.
  • Storage: sign-in tokens are kept on the user's Mac in an encrypted file, with the encryption key in the macOS Keychain. A local record of exports (such as note titles, file names and file identifiers) is also kept on the Mac.
  • Sharing: Google user data is not sold, shared with or transferred to anyone, and is not used for advertising or to train AI models.

Note Ferry's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other storage providers

If the user chooses Dropbox, OneDrive or S3-compatible storage, the selected exports are sent to that provider under its own terms.

Removing access and data

The user can disconnect an account in the app, or revoke Google access at myaccount.google.com/permissions. Local app data is in ~/Library/Application Support/NotesExporter and can be deleted at any time. Exported files stay wherever the user saved them until the user deletes them.
